## 2. Описание структуры данных Trie
Trie представляет собой дерево, в котором каждая вершина соответствует одному символу.  
Строка хранится как путь от корня до вершины, помеченной как конец слова.

Каждый узел дерева содержит:
- массив дочерних узлов размером 26 (по числу букв английского алфавита);
- булевый флаг `isEnd`, обозначающий конец слова.

Trie поддерживает только буквы `a`–`z`.  
Все входные данные приводятся к нижнему регистру.

## 3. Реализованные операции

### 3.1 insert(String word)
Добавление слова в дерево.  
Недопустимые символы вызывают ошибку.  
Пустая строка и `null` не добавляются.

### 3.2 contains(String word)
Проверка, содержится ли слово целиком в дереве.

### 3.3 startsWith(String prefix)
Проверка, существует ли хотя бы одно слово, начинающееся с указанного префикса.

### 3.4 getByPrefix(String prefix)
Возвращает все слова, начинающиеся с данного префикса.  
Поиск выполняется с использованием рекурсивного обхода.

### 3.5 clear()
Полностью очищает дерево.  
Реализуется созданием нового корневого узла.

## 4. Собственные коллекции

### 4.1 MyList<T>
Обобщённый интерфейс списка с методами:
- `void add(T value)`
- `T get(int index)`
- `int size()`

### 4.2 MyArrayList<T>
Реализация динамического массива:  
хранение элементов в `Object[]`, удвоение размера массива при переполнении, проверка границ индексов.  
Стандартные коллекции Java не используются.

## 5. Ограничения
Допускаются только символы `a`–`z`.  
Регистр не учитывается.  
Слова не могут быть пустыми.  
Стандартные коллекции Java запрещены.

## 6. Сложность операций
Сложность операции insert:
O(n), где n — длина добавляемого слова.

Сложность операции contains:
O(n), где n — длина проверяемого слова.

Сложность операции startsWith:
O(n), где n — длина префикса.

Сложность операции getByPrefix:
O(n + m), где
n — длина префикса,
m — количество найденных слов.

Сложность операции clear:
O(1).
